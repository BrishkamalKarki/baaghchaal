src/
	ui/
		game_scenes/
			-startup_scene (initial screen has play, info, exit)
			-game_configer_scene (modes selections in here: 1/2 player, play as goat/tiger, bot difficulty level)
			-board_scene (main game board in here, just a board with lines drawn automatically)
			-result_scene
			-scene_core (all the scenes inherits from here)
			-ui_config (themes, font, music, etc.)
			-resource_manager (managing the texts, fonts, musics, textures, etc.)
		board/
			-board_config (coordinates of each board points saved acc to current window size)
			-pieces_view (animations of the pieces, loading the pieces into the boards in the given coordinates)
			-board_elements (adding the layers of the ui like turns, goats, how many remained, all ui visuals)
		widgets/
			-button
			-rouned_rectangle
		-viewport (for handling the resize in the screen)

	game/
		-game_state (current info on the board, gets updated every time)
		-rules (game win conditions, playable conditions defined)
		-game_session (handling the flow of logic for the correspoding modes)
		
	engine/
		bot/
			-minimax
		logic/
			-board_evaluator (checking the playable positions to play, checking the winner)
			-move_evaluator (checking a move can be played there or not)
			
	core/
		-game_manager (game loop)
		-event_manager (handling events like changing the screen)
		-config (sizes for now)


# we will center the origin of every elements due which while changing the screen size,
ratio = current_size / max_size 
so ani size of each ui element = size at max screen * ratio and coordinate of each ui element = coordinate at max_size * ratio : this maintains the size even when screen is resized
